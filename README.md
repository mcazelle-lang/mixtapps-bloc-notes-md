# 📓 Bloc-notes Markdown

Le Bloc-notes de Mr Basic, version dev : écris en Markdown et vois le rendu en direct, en édition, en aperçu ou côte à côte. Export en .md.

- **Essayer** : https://mixtapps-demos.web.app/bloc-notes-md/
- **Sur Mixtapps** : https://mixtapps.com/u/lucas-bernard/cqfvnH4odMU4MAEm5OrE (app de démonstration du compte Lucas Bernard)
- **Remix de** [Bloc-notes](https://github.com/mcazelle-lang/mixtapps-bloc-notes)
- **Remixer** : sur Mixtapps, « ⚡ Remixer le code » lance l’app dans ton navigateur et un agent IA modifie
  son code ; ton remix est publié sur une branche GitHub à ton nom.

## Lancer en local

Une app statique (HTML, CSS, JavaScript, sans dépendance) : ouvre `index.html`, ou avec Node :

```bash
npm install
npm run dev
```
